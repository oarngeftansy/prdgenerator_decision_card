# Gameplay Planning Schema

Required sections:

1. Analysis scope and source video
2. Scene timeline
3. Player objective and fantasy
4. Core loop
5. Player operations
6. Event causal chains
7. Rules and constraints
8. Game state machine
9. Scoring, resources, and values
10. Win, loss, settlement, and retry
11. Feedback and presentation
12. UI/HUD and component structure
13. Evidence index
14. Inferences, unknowns, and questions
15. Acceptance criteria

Every evidence row includes `sceneId`, `frameId`, `timestamp`, `evidenceLevel`, and `confidence`.
