# 54 Typography Formula Index

This reference summarizes the layout formulas as reusable design heuristics. Use it for visual analysis, UI reconstruction, poster/layout generation, and PRD writing.

## Core Operating Model

Every formula should be converted into:

- **Structure**: grid, axis, focal point, reading path.
- **Density**: where content is heavy, light, empty, repeated, or layered.
- **Style**: font mood, asset style, material treatment.
- **Action**: for interactive UI, what motion or feedback preserves the visual logic.

## Formula Catalogue

1. **Full-screen Layout**: Fill the page with one dominant background/image/type system. Keep it full but not clogged. Use light, gradients, or blur as breathing space. Good for heroes and covers.
2. **Faded Layout**: Use low saturation, transparency, soft contrast, and partial disappearance. Keep one small solid anchor so the page does not dissolve.
3. **Circular Layout**: Build a central focus and orbital information flow. Use invisible circles, radial spacing, and density changes.
4. **Floral Layout**: Use plant/flower direction as a visual guide. Let stems, petals, or vines lead typography and create soft hierarchy.
5. **Module Layout**: Divide the page into grids/modules. Use module size, contrast, and spacing to create hierarchy.
6. **Symmetry Layout**: Establish a clear axis. Mirror visual weight, but vary details to avoid stiffness.
7. **Asymmetry Layout**: Offset the focal point while balancing visual weight through density, distance, and guiding lines.
8. **Centered Layout**: Place a strong focus near the center. Keep edges breathable and use subtle supporting elements.
9. **Line Layout**: Lines divide, guide, emphasize, or support. Thick lines set direction; thin lines set order.
10. **Border Layout**: A border gathers attention and stabilizes content. Leave enough inset space between content and frame.
11. **White Space Layout**: Use emptiness to strengthen focus. Margins of roughly 8-12% often create breathing room.
12. **Column Layout**: Use 2-4 columns for clarity. Column width:gutter near 6:1 is a stable baseline.
13. **Curved Layout**: Use arcs as reading paths. Keep curve direction clear and place text/assets along the flow.
14. **Retro Layout**: Choose a historical visual language, then organize it with modern clarity. Avoid random vintage clutter.
15. **Minimalist Layout**: Keep only the essential 1 main + 1 support structure. Precision of spacing and alignment matters more than decoration.
16. **Horizontal Layout**: Build calm horizontal rhythm. Useful for timelines, galleries, and wide editorial compositions.
17. **Vertical Layout**: Use vertical stacking, scroll rhythm, and height contrast. Good for mobile and poster-like hierarchy.
18. **Misplaced Layout**: Deliberately offset elements. The misplaced element must still obey an invisible order.
19. **Wraparound Layout**: Let text or elements wrap around a subject. Maintain legibility and consistent distance.
20. **Collage Layout**: Combine cutouts, photos, paper, stickers, and fragments. Keep one logic: color, angle, theme, or hierarchy.
21. **Text Layout**: Make typography itself the visual. Use size, weight, line-height, spacing, and rhythm as composition.
22. **Handwriting Layout**: Use handwritten or casual marks for intimacy. Pair with clean structure so it stays readable.
23. **Ceramic Layout**: Use smooth, glossy, rounded, light-reflective material cues. Emphasize glaze, highlights, and soft shadows.
24. **Glass Layout**: Use transparency, blur, edge highlights, and layered depth. Ensure contrast remains readable.
25. **Perspective Layout**: Use vanishing direction and scale to create depth. Keep text aligned to the perspective logic.
26. **Dynamic Layout**: Use motion cues: tilt, blur, repetition, speed lines, or staged positions. Good for action and transitions.
27. **Blurred Layout**: Blur secondary layers to create depth, memory, or speed. Keep the primary reading layer crisp.
28. **Tape Layout**: Use tape, label, sticker, or pasted materials. Specify paper/plastic opacity, torn edges, shadow, and rotation.
29. **Textile Layout**: Use fabric texture, thread, weave, fold, or softness. Pair with tactile spacing and warm shadows.
30. **Color Block Layout**: Use large color planes as structure. Blocks must define hierarchy, not just decorate.
31. **Slice Layout**: Cut images or text into slices. Maintain alignment logic and a stable anchor.
32. **Triangle Layout**: Build hierarchy through triangular arrangement. Useful for stability plus direction.
33. **Overlapping Layout**: Layer elements with controlled depth. Define front/middle/back and shadows/opacity.
34. **Shadow Layout**: Use shadow as structure, focus, or material. Specify shadow direction, softness, spread, and opacity.
35. **Graffiti Layout**: Use marks, spray, scribbles, or rebellious type. Balance chaos with a clear focal point.
36. **Eye Element Layout**: Eyes create a focus point and directional gaze. Use gaze direction as an invisible guide line.
37. **Hand-drawn Layout**: Use loose lines, circles, arrows, doodle icons, or sketch marks. Put them at structural points.
38. **Gradient Layout**: Gradient needs direction and speed. Keep content stable on top of color flow.
39. **Ink Spread Layout**: Use ink bloom, feathered edges, dry grain, or wash. Dark ink builds structure; pale ink builds air.
40. **Water Ripple Layout**: Use circular or linear waves. 3-5 layers usually read as natural depth.
41. **Black & White Layout**: Black sets force; white sets breath. Choose an intentional black:white ratio such as 8:2 or 7:3.
42. **Organic Layout**: Use curves and irregular natural flow. Balance non-geometric shapes with a clear direction.
43. **Up-and-Down Layout**: Decide whether top or bottom is dominant. Space between zones should grow with headline size.
44. **Left-and-Right Layout**: Put logical/detail content on one side and openness or image weight on the other.
45. **Torn Layout**: Torn edges should appear on boundaries; keep the content center stable and clean.
46. **Diagonal Layout**: Use 15-25 degrees for mild motion, 30-45 degrees for strong tension. Keep weight balanced.
47. **Three-dimensional Layout**: Use perspective, layers, light, and proportional scale. Distinguish foreground, middle, background.
48. **Pixel Layout**: Use grid units, blocks, repeated modules, and digital nostalgia. Keep grid sizes consistent.
49. **High-Saturation Layout**: Use strong color for impact but keep the focal structure stable. Add lower-saturation support colors.
50. **Hand Element Layout**: Hands or pointing gestures guide attention. Gesture direction must be clear.
51. **Grainy Layout**: Use noise, sand, paper, or particle texture to add warmth and depth. Keep layers ordered.
52. **Sticky Notes Layout**: Use note blocks, slight rotation, color separation, and layered shadows. Keep note hierarchy clear.
53. **Checkerboard Layout**: Use repeated grid contrast. Keep square size and color logic consistent.
54. **Golden Ratio Layout**: Use 1:1.618 divisions and golden focal points. Make main/support proportions feel natural.

## UI Reconstruction Add-on

When these formulas are applied to interactive web/app screens:

- Convert visual formula into layout constraints: grid, aspect ratios, safe margins, alignment anchors.
- Convert material formula into CSS: texture image, noise overlay, box-shadow, border, blur, opacity, mix-blend-mode.
- Convert motion formula into interaction specs: trigger, target, from-state, to-state, duration, easing, and completion state.
- For video frames, allow "same as previous frame" only if the frame describes the exact difference or animation stage.
