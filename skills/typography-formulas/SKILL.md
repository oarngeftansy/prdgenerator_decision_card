# Typography Formulas

Use this skill to turn visual material into practical layout decisions. The source model is a 54-formula typography system: each layout style is treated as a reusable composition pattern rather than a fixed template.

## Workflow

1. Identify the content goal: informational, emotional, product-focused, editorial, playful, luxurious, retro, handmade, technical, or cinematic.
2. Detect the dominant layout formula already present, or choose 1-3 formulas to apply.
3. Translate formulas into implementable specs:
   - grid and alignment
   - focal point and visual path
   - whitespace and density
   - type hierarchy and font mood
   - image/asset style
   - decorative material treatment
   - motion/interaction feedback when the output is UI
4. Reject vague descriptions. Name concrete layout devices: centered axis, 1/3 focal point, 8-12% page margin, 6:1 column-to-gutter ratio, diagonal tension, circular orbit, overlapping layers, paper texture, grain, glass blur, shadow depth.
5. For reconstruction tasks, preserve the original formula first; do not replace a poetic/editorial composition with default dashboard or card UI.

## Formula Selection

Use [references/formulas.md](references/formulas.md) when you need the full 54-formula index or style-specific rules.

Fast selection:

- **High impact hero**: full-screen, high-saturation, black-white, diagonal, 3D, perspective.
- **Soft emotional page**: faded, floral, white-space, ink-spread, water-ripple, grainy.
- **Precise product/UI layout**: module, symmetry, column, border, line, golden-ratio.
- **Editorial/fashion feel**: asymmetry, centered, retro, text, overlapping, shadow.
- **Handmade/cute/playful feel**: handwriting, hand-drawn, graffiti, sticky-notes, tape, collage.
- **Material-driven visual**: ceramic, glass, textile, paper/torn, grainy, pixel.
- **Motion-like composition**: curved, circular, dynamic, organic, diagonal, slice.

## Visual Analysis Checklist

When analyzing a screenshot, frame, or video:

- **Formula**: Which layout formula drives the page? Is it centered, modular, white-space, collage, diagonal, etc.?
- **Focal point**: What grabs the eye first? Where is it placed: center, golden point, top third, edge, diagonal path?
- **Visual path**: How does the eye move: left-to-right, top-to-bottom, circular orbit, curve, diagonal, scattered collage?
- **Density**: Which areas are heavy, light, empty, or intentionally crowded?
- **Type**: What is the font mood: elegant serif, neutral sans, handwritten, retro display, condensed, geometric, playful?
- **Assets**: For every visual element, state style: cute vs realistic, hand-drawn vs photographic, flat vs skeuomorphic, soft vs high contrast, paper vs glass vs fabric vs grain.
- **Material**: Note texture, blur, opacity, shadow, paper grain, tape, torn edge, sticker, fold, reflection, lighting.
- **UI states and motion**: For click, hover, focus, input, selection, swipe, submit, share, flip, popup, or preview updates, define trigger, target, from/to, duration, easing, and feedback.

**For game UI analysis**, also capture:
- **HUD layout**: Score display, health/energy bars, timer, combo counter, level indicator — where are they placed and how do they use the formula system?
- **Game state screens**: Menu, playing, pause, victory, defeat, shop, inventory — each may use a different formula.
- **Game feedback overlay**: Score popups, particle effects, screen shake, damage numbers, collect animations — these are separate visual layers that must work with the base formula.
- **Game-specific materials**: Pixel art, cel-shaded, hand-drawn, neon, retro arcade, isometric, top-down, side-scroll — these material choices affect the formula selection.

## Output Rules

For PRDs and reconstruction documents, include these sections when relevant:

- Layout formula summary
- Component inventory
- Asset and decoration style inventory
- Typography hierarchy
- Spacing and grid rules
- Motion and interaction feedback
- Frame-by-frame differences for video
- Acceptance checks comparing screenshots against source frames

Do not copy long source text from the PDF. Paraphrase the formulas as design rules and implementation guidance.
