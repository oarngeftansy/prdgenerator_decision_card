# 阶段 1：决策卡验收用例

## 用例矩阵

| ID | 场景 | 必须验证的结果 |
|---|---|---|
| TC1 | 素材证据足以唯一判断 | 不生成决策卡，AI 直接填写有来源的结论。 |
| TC2 | 存在多种合理解释且素材不足 | 显示完整卡片：至少两个可执行选项、推荐项及理由、判断依据、单/多选说明、自己填写、暂时跳过、保存后会更新、应用选择。 |
| TC3 | 单选问题 | 只能选择一个选项；未选择时应用给出明确错误；应用后只保存一个结论。 |
| TC4 | 多选问题 | 可选择多个兼容选项；互斥或数量限制有明确说明和校验。 |
| TC5 | 自己填写 | 自定义内容可保存、刷新恢复，并进入 P4 可见正文；来源标记为策划填写。 |
| TC6 | 暂时跳过 | 问题保持未解决，不进入正式正文；P7 导出被门禁阻止并指出缺口。 |
| TC7 | 跨页面一致性 | P1、P4、P5、P6、P7 消费同一决策及状态，不出现旧值或不同卡片。 |
| TC8 | 下游失效传播 | 修改已应用决策后，相关章节确认、图解、表格和预览被标记过期并要求复核；无现存下游产物时标为本轮不适用。 |
| TC9 | P7 正文隔离与导出门禁 | 未解决问题不冒充正式结论；全部决策解决并重新审核后，完成度统一更新且导出恢复。 |

## 截图最低集

- TC1：明确证据页面且无决策卡。
- TC2：完整卡片展开状态。
- TC3/TC4：选择限制或错误状态，以及应用后的结果。
- TC5：填写前、应用后、刷新后、P4 正文结果。
- TC6：跳过状态与 P7 导出阻断。
- TC7：P1/P4/P5/P6/P7 对应状态。
- TC8：修改前后及下游过期提示；条件不具备时不得伪造截图。
- TC9：未解决时正文与门禁、解决并复核后的统一完成状态。
