# Interaction Planning Schema

Required sections:

1. Analysis scope and user goal
2. Scene/page/dialog timeline
3. User task flow
4. Region and component hierarchy
5. Component inventory and persistent tracks
6. Interaction event causal chains
7. Component states and validation
8. Motion and immediate feedback
9. Assets and visible content
10. Loading, empty, error, permission, and network states
11. Device and responsive unknowns
12. Evidence index
13. Inferences and questions
14. Acceptance criteria

Every event includes trigger, target, before state, response, after state, evidence level, confidence, and timestamps.
