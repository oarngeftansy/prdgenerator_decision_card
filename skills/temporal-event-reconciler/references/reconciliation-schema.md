# Reconciliation Schema

Fact: subject, predicate, value, start, end, scene IDs, frame IDs, evidence level, confidence.

Event: before state, input, response, after state, timestamp range, evidence references.

Conflict: type, competing claims, evidence for each claim, severity, recommended review action.

Required conflict types: causal gap, unreachable state, terminology mismatch, value contradiction, component identity conflict, missing boundary.
