# Calibration Rubric

Score each dimension from 0–5:

- Coverage: required sections and important events
- Evidence alignment: conclusions supported by correct timestamps
- Causal accuracy: operations and state transitions reconstructed correctly
- Domain accuracy: gameplay rules or interaction behaviors use correct terminology
- Uncertainty discipline: facts, inferences, and unknowns separated
- Granularity: detail matches the approved planning document
- Structure and style: headings, tables, phrasing, and ordering

Record false positives, omissions, wrong timestamps, wrong state transitions, and unsupported certainty as separate regression cases.
