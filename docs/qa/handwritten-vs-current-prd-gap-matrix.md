## 当前不可放行项

以下任一项存在时，不能判定与人工策划文档颗粒度对齐：

1. 任一适用机制仍使用空 `formulae`、空 `fieldDictionary` 或空生命周期，却在页面显示“通过”。
2. GVE16 或其他样例的项目专属事实进入当前正文，但没有当前素材或用户决策依据。
3. 逻辑规则与界面表现混在同一条执行步骤中。
4. 章节用截图示例值代替配置来源、计算口径或状态规则。
5. 图解未绑定章节或已标记 stale，仍出现在预览或飞书导出。
6. 同一规则在概述、流程、关键规则和属性段落同义重复。
7. 待决策内容只显示“待确认”，没有可执行选项、影响范围和应用后的更新目标。

## 后续验收要求

- 九个维度均需逐章给出结论，不允许只出一张总分表。
- 每个“当前有”必须指向当前模型字段或预览段落。
- 每个“手写文档有”必须指向 H1/H2/H3 的章节或行号。
- 每个“缺失”必须有明确补写载体：正文、配置映射、公式、图解、表格或决策卡。
- 每个“多余”必须说明删除、移入草图、移入知识库或改为证据注释。
- 修复后重跑同一矩阵；只有“缺失=0、越权事实=0、过期图=0”才允许进入最终导出。
