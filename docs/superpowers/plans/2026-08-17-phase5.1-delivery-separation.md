# Phase 5.1 Delivery Separation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build deterministic VisualBlocks and a Logic-only Execution Delivery without changing Rules, Gaps, Entity Graph, P7, UI, or parameters.

**Architecture:** `visual_delivery.py` converts each approved Presentation Rule into one VisualBlock by consuming Phase 5 audited Entity references and a real screenshot index. `logic_delivery.py` filters existing MechanismBlocks to non-presentation rule types and adds stable VIS references only for deterministically linked Logic Rules. A reference generator creates six-chapter comparison and quality-audit artifacts without writing into product state.

**Tech Stack:** Python 3.12, dataclass-free JSON-compatible dictionaries, pytest, existing Phase 4.3 MechanismBlocks and Phase 5 Entity Graph.

## Global Constraints

- Preserve the existing eight-step product flow; P3 remains interaction-deliverable review and P5 remains diagram review.
- Do not modify Entity Graph, Rule, Gap, parameters, P7 export, six-chapter Phase 4.3 source artifacts, or UI.
- Logic-only delivery accepts only `logic`, `flow`, `numeric`, `config`, and `interaction` Rules.
- `relatedEntityIds[]` must be copied from Phase 5 audited references and never re-inferred.
- A derived Logic association requires shared Entity, compatible mechanism semantic, and evidence-chain intersection simultaneously.
- Only evidence-index entries explicitly typed `screenshot` may enter `sourceScreenshotIds[]`.
- Presentation backflow, unsupported semantic additions, confirmed Gap rendering, and Presentation Rules in Logic body must all remain 0.

def build_visual_blocks(presentation_rules, logic_rules, entity_graph, evidence_index):
    audited = {item["ruleId"]: item["relatedEntityIds"] for item in entity_graph["presentationRuleReferences"]}
    entity_ids = {item["entityId"] for item in entity_graph["entities"]}
    blocks = []
    for rule in presentation_rules:
        related = audited[rule["ruleId"]]
        if not related or not set(related) <= entity_ids:
            raise ValueError("audited Entity reference is missing or invalid")
        blocks.append(_build_visual_block(rule, related, logic_rules, evidence_index))
    return blocks
```

ALLOWED_EXECUTION_RULE_TYPES = {"logic", "flow", "numeric", "config", "interaction"}

def _logic_only_block(block):
    projected = deepcopy(block)
    projected["presentation"] = []
    for role in EXECUTION_ROLES:
        projected[role] = [entry for entry in projected.get(role, []) if entry.get("ruleType") in ALLOWED_EXECUTION_RULE_TYPES]
    projected["ruleIds"] = sorted({entry["ruleId"] for role in EXECUTION_ROLES for entry in projected.get(role, [])})
    return projected
```
