> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce six deterministic GVE16-paradigm mechanism samples without adding planning semantics.

**Architecture:** A composer maps approved structured rules into evidence-preserving MechanismBlocks using ChapterType, SchemaSlot, Rule fields, and schema content groups. A controlled renderer turns blocks into paragraphs using only abstract style rules.

**Tech Stack:** Python, pytest, JSON/Markdown artifacts.

## Global Constraints

- No raw GVE16 sentence or project content is readable at runtime.
- Gaps never populate confirmed block fields or close themselves.
- Different semantic keys remain individually traceable and cannot be merged solely to create a complete-looking chain.
- Stop after the six reference chapters.
