# 主策视角工作台自检

检查口径：第一次接触该项目的主策，是否能立即理解当前目标、下一步动作、当前结论、阻断原因和最终产物。

| Priority | Location | Finding | User impact | Required fix | Status |
|---|---|---|---|---|---|
| P0 | 环节确认 | 后端语义细节未确认时曾直接拒绝确认，前端表现为点击无反应 | 无法继续主流程 | 语义缺口降级为待确认；仅结构错误阻断 | 已修复 |
| P1 | 环节确认 | 确认后没有可靠进入下一环节 | 策划误以为保存失败 | 保存成功后选择下一未确认环节；最后一项进入交互预览 | 已修复 |
| P1 | 页面审核 | 默认铺开代表帧、组件状态和内部字段 | 策划无法按玩家行为理解流程 | 改为“操作前→玩家操作→系统反馈→操作结果”，原始截图按需展开 | 已修复 |
| P1 | 交互预览 | 预览摘要暴露版本、代表帧数量和问题 ID | 最终交付认知被内部实现干扰 | 改为策划草图、竞品参考及中文结果状态 | 已修复 |
| P2 | 顶部阶段导航 | “流程、页面、图解”等标签缺少任务含义 | 不知道各阶段要完成什么 | 改为五个完整策划任务名称，并把图解归入玩法审核 | 已修复 |
| P2 | 环节命名 | 历史任务使用“场景 1、场景 2” | 无法快速定位审核内容 | 后端语义化命名；无法命名时显示“待命名环节” | 已修复 |
| P2 | 保存反馈 | 保存过程和失败原因缺少稳定可见状态 | 重复点击或误判无响应 | 增加“正在保存”、失败保留内容和重试提示 | 已修复 |
| P2 | 移动端入口 | 任务历史位于工作台上方，占据首屏 | 进入审核后仍需滚动寻找工作台 | 审核模式隐藏历史面板，项目入口保留在工作台 | 已修复 |
| P3 | 移动端阶段导航 | 五个长阶段名称在窄屏会形成多行按钮 | 可用但首屏较高 | 后续可改为当前阶段标题加横向步骤摘要 | 待优化 |
| P3 | 原始截图高级编辑 | 抽屉内仍保留为画板生成服务的区域标注能力 | 新手展开后学习成本较高 | 后续增加“普通查看/高级标注”二级入口 | 待优化 |

## 结论

当前没有遗留 P0 或 P1。主流程已经从模型数据审核改为策划行为审核；内部证据仍完整保留，用于策划草图、问题定位和历史任务兼容。剩余两项为不阻断交付的 P3 优化。
