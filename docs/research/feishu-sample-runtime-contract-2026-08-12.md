# 飞书样例规则的底层运行合同

本合同不是写作建议，而是生成、规范数据、审核门禁、P7/飞书渲染和测试共同遵守的执行规则。知识库中的武器、Buff、背包、扫荡等只作为方法储备；当前素材没有对应事实时不得生成。

| 样例规律 | 生成与数据合同 | 审核与交付合同 |
| --- | --- | --- |
| 目录随实际玩法组织 | 从素材识别系统、子系统、机制，不复用固定目录或固定小标题 | 重复命名、空章节、稀疏章节拆分过细时阻断或合并 |
| 概述先回答玩家怎么玩 | 写目标、基础操作、核心循环、成长反馈、胜负；短内容分行，不堆成一段 | 页面布局、按钮说明和对象名词不能冒充玩法概述 |
| 证据决定可写范围 | 截图只证明可见对象、状态、顺序、反馈和显示数值；文档、配置、策划决定才可支持隐藏规则 | 禁止从画面编造公式、概率、重置、持久化或正式字段名 |
| 多对象必须有内容清单 | 可见武器、技能、词条、敌人、奖励等逐项记录名称、类型、效果、数值、状态和来源 | 不允许用“存在多种武器”等概括句替代清单 |
| 属性先写正文再进表 | 所有存在属性的核心对象分别以对象名作为大标题，再由 `attributeSections` 按真实业务责任分组；逐项说明含义、所属对象、参与的计算/判断、读写或生效时机、边界 | 不得只为单个对象建立属性章节；`parameterSchema` 不能替代属性正文；表格只集中承载值、单位、范围和来源；禁止把表格逐行生硬文本化 |
| 参数命名就近映射 | 有权威表名/字段名时，在所属行为后写“业务名 → 表/字段”；无权威来源时不得伪造正式名称 | 已采用的命名直接作为结论，不再显示“建议”；生命周期不混入参数命名 |
| 执行顺序要闭环 | 写触发、前置状态、系统处理、玩家选择、状态变化、结果、退出/重入/结算/活动结束 | 只在真实多步流程中编号；短机制用连续自然正文 |
| 随机机制按证据展开 | 适用时覆盖进池资格、排除、权重、顺序、放回、重复、空结果、暂存、确认、刷新成本和重置 | 不因“随机”类别自动补造缺失规则；真实歧义进入决策卡 |
| 公式必须可追溯 | 写变量含义、类型、单位、来源、计算顺序、取整；证据完整时给代入算例 | UI 数值不能单独证明公式；不完整关系不得冒充正式公式 |
| 图解与正文结合 | 流程图嵌在解释的机制内：图前写触发和当前状态，图后继续写分支结果、参数、边界或重置 | 图不能独立成证据墙；纯文字和单公式不生成无意义图解 |
| 截图就近说明 | 局部截图放在它证明的布局、状态对比或规则步骤附近 | 竞品截图明确可见信息、采用点和推导边界，不冒充本项目事实 |
| 标题按信息量生成 | 复杂机制拆分，多个稀疏兄弟机制合并；保留帮助阅读的业务小标题 | 禁止固定“规则与边界/正常流程/特殊情况/怎么验证”等模板标题 |
| 对象标题去重 | 章节标题与属性对象标题指向同一对象时只保留对象名，原章节规则下沉为同级业务分组 | 禁止“战场推进与载具生存 → 载具”“武器槽位与自动攻击 → 武器”式连续重复标题；目录与正文同步合并 |
| 决策卡只处理真实歧义 | 至少两个可执行选项、推荐理由、自填、跳过、单/多选、证据和影响范围 | 未选择内容不进入正文；应用后同源更新正文、画板、表格和最终文档，并阻断未完成导出 |
| 正式正文只写业务 | 删除“素材只证明”“流程图只确定”“仍由决策卡确认”“留待阶段验证”等审核元话语 | 语言门禁检查废话、重复、内部术语、任务状态和证据能力说明 |
| P7 与飞书同源 | 两端读取同一已确认章节、属性分组、表格、图解、截图和决策状态 | 禁止 P7 有内容而导出丢失；完成度与导出门禁使用同一真实状态 |
| 反馈表逐条闭环 | 除“验收无误”外均保留为待修复项，并绑定修复、验证和证据 | 自动测试不能代替逐条复核；截图必须与用例唯一对应且完整可判定 |

## 强制执行路径

1. 生成提示：`backend/feishu_prd_depth_contract.py`、`backend/gameplay_analysis.py`。
2. 规范数据：章节的 `plannerSections.attributeSections`、`parameterSchema`、`formulae`、`diagrams`、`inlineFigures` 和决策状态。
3. 审核门禁：`backend/lead_planner_gate.py`、`backend/granularity_audit.py`、`backend/feishu_language_quality.py`、最终交付门禁。
4. 同源渲染：`js/final-document-preview.js` 与 `backend/gameplay_render.py`。
5. 自动测试：生成合同、规范化保留、颗粒度、语言、P7/飞书同源和导出阻断测试。

任何新增样例规则必须同时指出以上五层中的落点；只写入 Memory、Skill 或说明文档，不算完成。
